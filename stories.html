AI QA tool on AWS

Aug – Sep 2026Shipped AWS CDK · Lambda · API Gateway · GitHub Actions

The QA team's internal AI tool for drafting test cases only ran on a developer's laptop. I got it deploying to AWS as a serverless app.

  • Keyless deploys. GitHub Actions deploys to AWS through an OIDC role, so no long-lived AWS keys are stored in GitHub.
  • Working on a real account. I fixed the problems that only appear in a live AWS account, such as bucket naming, CORS, WebSocket permissions, IAM and log clean-up.
  • Leaner and steadier. I cut the main Lambda's memory from 1,536 MB to 512 MB, and made rapid or duplicate messages queue up one at a time per conversation.
  • Cleaner exports. I improved the Google Sheets export with stable rows, readable test-case IDs and tidy formatting.

Load-test staging

Sep 2026 – nowIn progress Terraform · GCP · MongoDB Atlas

QA needs to load-test our services against something that behaves like production, without touching production. I'm building the Terraform for a temporary staging environment.

So far I've built:

  • Staging from production configs. Staging versions of the Pub/Sub, IAM and Cloud Tasks setups, generated from the production Terraform values and validated before anything is applied.
  • Real data shape, no personal data. A short-lived MongoDB Atlas cluster restored from a production backup, with personal data masked by tested rules and checked before any service connects.
  • Service catalog. A tool that reads each service's code to find what it publishes, subscribes to and calls over HTTP, and audits that map against the current code.
  • Safe by default. The generated values refuse to target the production project, and the environment is designed to be destroyed after each test.

Fund performance summary

Oct 2026Released Mongoose · TypeScript · Changesets · shared npm package

Fund pages needed a short performance summary: a main figure with an optional return disclaimer, and a second supporting figure.

  • Data model. I designed the summary fields in the shared fund schema that Versa's services use: a main and a second slot, each with a value, label, short label and caption.
  • Careful release. I used Changesets to publish it as a pre-release first, so the service could build against it, then exited pre-release mode and released it as a versioned update once the fields settled.
  • API. The fund-details service now returns the summary only when both figures exist, and fills missing text with empty strings so the app always gets the same shape.
  • Review. The data model is released; the service change is in code review.

New MyKad support

Oct 2026In review Node.js · eKYC

The new-generation MyKad started being issued nationwide in September 2026, and the eKYC check would have rejected it.

  • Learned the provider first. I read through the identity-verification provider's documentation to understand how it reads a card and which document types it returns, including the new 2026 MyKad.
  • Found the cause. I traced our verification flow and found that the document check only accepted the older MyKad types, so the new card type would fail.
  • Small, safe fix. I added the new card type to the supported list, with no app or front-end change needed, and released it as a patch version with a changelog entry. It's now in code review.
  • Checked first. I ran the existing test suite against the fix on a scratch copy before changing the real service.

Quantum Research CampUniversity of Tsukuba, Japan

Sep 2026Completed

I went to the Quantum Research Camp at the University of Tsukuba with sessions at AIST and G-QuAT. I came in thinking quantum computers would one day replace CPUs. They won't: the future is CPU, GPU and QPU working together, with the QPU taking only the problems it is good at, the way GPUs sit alongside CPUs today.

Day one was the university museum and the stories of Tsukuba's three Nobel Prize winners. The next two days were at AIST, where we learned about MEMS, saw a sensor that picks up the sound of muscles to help study muscle loss in bedridden patients, and watched a quantum eraser experiment that shows light acting as both a wave and a particle.

AIST is also where we saw a real superconducting quantum computer. There are five types of quantum computer, and three of them are in Tsukuba. We learned how Josephson junction qubits work and why they have to be kept so cold, tried manual PCB design, and tested how RF components change at low temperature.

What surprised me most was quantum algorithms: almost every logic-gate rule I knew goes out the window. We closed the camp with a team presentation on what we learned and where quantum computing is heading.

Thanks to the University of Tsukuba, AIST and G-QuAT, our supervising lecturers Hadri Mokhtar and Saiful Dzulkefly Zan, and my teammates Thanush Govindarajoo and Ling Chuan Long.

Top Coders Malaysia 2025National final

Nov 2025Champion · UKM9th national

After winning first place in the UKM preliminary round, my team went into the national final feeling confident.

Then we got stuck on the first three problems, watching our solutions pass 90% of the test cases for an hour and a half. We solved two of the three. With an hour left we changed plan and went for the problems other teams were passing, and solved four more in that last hour. We worked out one more but ran out of time to implement it.

We finished 9th of 140 teams. No prize this time, but after that start it still felt like a win, and a real lesson in resilience and knowing when to switch plans.

Thanks to Thulija Technologies (T-Academy) and the Data Science Association for organising, and to Dr Noor Faridatul Ainun Zainal, FTSM student affairs coordinator, for covering our transport.

Hackathon Za'ba 2025Kolej Pendeta Za'ba, UKM

May 2025Champion

Hackathon Za'ba is a six-hour challenge to build a machine learning solution. It was our team's first hackathon and our first time putting machine learning into a project.

We built Marshall Assist: an LSTM network that recognises airplane marshalling gestures from video and gives trainee marshallers real-time feedback, so they can learn the standard signals faster.

It took first place.
